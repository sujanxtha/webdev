# Project 2a – Simple Product Viewer

## 1. Project Description

Simple Product Viewer is a web application developed for Project 2a: AJAX Call to a Live REST API.

The application retrieves product information from Fake Store API using JavaScript and displays product images, names, and prices. Users can select different categories to view specific products.

## 2. Features

- Fetch product information from a live REST API.
- Display product images, names, and prices.
- Select categories using a dropdown menu.
- Search for products using a Search button.
- Responsive webpage design.
- Basic error handling for unsuccessful API requests.

## 3. Technologies Used

- HTML5
- CSS3
- Native JavaScript
- Fetch API (AJAX)
- JSON
- Fake Store API

## 5. How to Use

1. Open the published application.
2. Select a product category from the dropdown.
3. Click the Search button.
4. View the product images, names, and prices.
5. Select another category to display different products.

## 6. Self-Assessment

I successfully developed a simple application using HTML, CSS, and native JavaScript.

The application retrieves live API data using the `fetch()` method and dynamically displays product information on the webpage.

I implemented a category dropdown, Search button, CSS styling, and basic error handling. Event handling is implemented dynamically using `addEventListener()`.

Through this project, I improved my understanding of AJAX, REST APIs, JSON responses, and DOM manipulation.

The application meets the main technical requirements. However, additional features such as searching by product name and advanced filtering could be implemented in the future.
