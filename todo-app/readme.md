To-Do List Web Application
Project overview
This To-Do List is a browser-based application created for a Web Development course using HTML, CSS, and JavaScript. Users can add, complete, filter, and delete tasks. Tasks are stored in the browser so they remain available after a page refresh.
Features
- Add a new task through a form
- Validate input and display an error message for empty or too-short tasks
- Mark tasks as completed or active
- Delete individual tasks
- Filter tasks using All, Active, and Completed buttons
- Clear completed tasks
- Display a count of active tasks
- Save and restore tasks with localStorage
- Responsive interface
Technologies
- HTML5: Page structure, form, buttons, and task list
- CSS3: Layout, styling, validation feedback, and responsive design
- JavaScript: Event handling, DOM updates, filtering, and data storage
- GitHub Pages: Hosting the published website
How to use
1. Enter a task and click Add.
2. Tick the checkbox to mark a task as completed.
3. Use All, Active, or Completed to filter the list.
4. Click Delete to remove a task.
5. Use Clear Completed to remove completed tasks.
6. Refresh the page to see that remaining tasks are retained.
